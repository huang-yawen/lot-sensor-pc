

# LOT Sensor PC 物联网传感器管理平台

LOT Sensor PC 是一套面向物联网设备运维与数据监测场景的传感器管理平台。系统围绕传感器数据采集、设备状态管理、行为数据分析、故障信息追踪与远程指令配置等核心能力构建，提供从数据接入、业务处理、可视化展示到设备联动控制的完整闭环。

平台采用前后端分离架构，前端基于 Vue 3 生态构建高交互数据看板，后端基于 Node.js 与 Express 提供 RESTful API 服务，并结合 MySQL 与 MQTT 完成数据持久化和设备消息通信。整体设计强调实时性、可维护性与业务扩展能力，适用于传感器监控、设备管理、边缘设备联动和物联网实验平台等应用场景。

## 核心能力

- 实时数据监测：面向传感器数据和行为数据提供实时展示能力，支持关键指标快速感知。
- 汇总数据追踪：沉淀传感器与行为数据记录，便于趋势分析、异常回溯和运行评估。
- 设备统一管理：支持设备基础信息维护，覆盖新增、删除、更新和列表查询等管理流程。
- 指令配置下发：提供设备指令配置界面，通过 MQTT 实现配置同步与设备侧联动。
- 故障信息分析：记录并展示异常数据，支持故障类型统计与运维问题定位。
- 可视化数据呈现：集成图表、表格、分页与模块化布局，提升运行态势展示效率。

## 技术架构

系统由前端展示层、后端服务层、数据存储层和设备通信层组成：

- 前端展示层负责页面路由、状态管理、数据请求、组件化展示与图表渲染。
- 后端服务层负责接口聚合、业务控制、数据校验、数据库访问与 MQTT 消息发布。
- 数据存储层基于 MySQL 保存传感器、设备、行为、故障与指令相关业务数据。
- 设备通信层基于 MQTT 订阅传感器、行为、故障与存活检测主题，实现设备消息接入。

## 技术栈

| 分层 | 技术 | 说明 |
| --- | --- | --- |
| 前端框架 | Vue 3 | 基于组合式 API 构建模块化前端应用 |
| 构建工具 | Vite | 提供快速开发服务与生产构建能力 |
| UI 组件 | Element Plus | 提供表单、表格、布局等企业级界面组件 |
| 状态管理 | Pinia | 管理传感器、设备、指令、分页和异常等业务状态 |
| 路由管理 | Vue Router | 管理实时数据、汇总数据、设备管理和故障信息等页面 |
| 数据可视化 | ECharts | 支撑折线图、柱状图、饼图等数据图表展示 |
| HTTP 通信 | Axios | 统一封装前后端接口请求 |
| 后端框架 | Express | 提供 RESTful API、静态资源托管和服务启动能力 |
| 数据库 | MySQL / mysql2 | 负责业务数据持久化与异步数据库访问 |
| 消息通信 | MQTT.js | 连接 MQTT Broker，完成主题订阅与指令发布 |
| 数据校验 | Joi | 支撑后端业务参数校验 |

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 传感器实时数据 | 展示传感器最新采集数据，辅助实时监控设备运行状态 |
| 传感器汇总数据 | 查询并展示传感器采集记录，支持运行趋势分析 |
| 行为实时数据 | 展示设备或用户行为相关实时数据 |
| 行为汇总数据 | 查询并展示行为数据记录，便于回溯与统计 |

| 故障记录 | 展示异常信息与故障分类统计，辅助问题定位 |

## 快速启动

### 环境要求

- Node.js 18 或更高版本
- MySQL 8 或兼容版本
- MQTT Broker，例如 EMQX、Mosquitto 或其他兼容服务

### 前端启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

### 后端启动

```bash
cd backend
npm install
node server/app.js
```

后端服务默认运行在：

```text
http://localhost:3000
```

### 数据库配置

导入数据库脚本：

```text
backend/wusiqi.sql
```

当前数据库连接默认配置为：

```text
mysql://root:123456@localhost:3306/task
```

如需调整连接信息，可修改：

```text
backend/server/config/promisepool.js
```

### MQTT 配置

当前 MQTT 默认连接地址为：

```text
mqtt://localhost:1883
```

订阅主题覆盖设备存活检测、传感器数据、行为数据与故障数据：

```text
isAlive/#
SensorData/#
BehaviorData/#
ErrorData/#
```

如需修改 Broker 地址、认证信息或订阅主题，可调整：

```text
backend/server/mqtt/index.js
```

## 构建与部署

前端通过 Vite 生成生产资源：

```bash
npm run build
```

构建产物默认输出至 `dist` 目录。后端服务已配置静态资源托管逻辑，可根据实际部署目录调整 `backend/server/app.js` 中的静态资源路径。

## 项目定位

LOT Sensor PC 以“数据可视、设备可管、指令可达、异常可追踪”为核心目标，面向物联网设备运行管理提供清晰、稳定、可扩展的 PC 端管理能力。通过前端可视化能力与后端实时通信能力的结合，平台能够支撑设备数据从采集到分析、从配置到联动的完整业务链路。
